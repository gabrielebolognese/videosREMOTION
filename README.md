# videosREMOTION

Remotion video projects.

## Projects

| Folder | Description |
| --- | --- |
| [`my-video`](./my-video) | Main Remotion project — brand, agency, cafe, day-zero and offer compositions. |
| [`comp-videos`](./comp-videos) | Side-by-side comparison video compositions. |

## Getting started

Each folder is a standalone Remotion project. From inside either one:

```bash
npm install     # install dependencies
npm run dev     # open the Remotion Studio preview
npm run lint    # eslint + typecheck
```

`my-video` also has render scripts that write to `out/`:

```bash
npm run render           # HundredDays
npm run render:dayzero   # DayZero
npm run render:agency    # AgencyExplainer
```

## Notes

- `node_modules/`, `out/` and `build/` are not tracked — they are regenerated by the commands above.
- Source media lives in each project's `public/` folder and **is** tracked.
